# CUtils has moved

CUtils now lives in its own repository: **https://github.com/creep-ltx/cutils**

It is written in C there and has grown to fifteen commands (cat grep head tail
wc find ls cp mv rm mkdir touch tee du df). The Amiga E versions that were here
moved along, with their history, into its `e/` folder. Their old releases
(ls 0.3.4, cp 0.1.2, mv 0.5, mkdir 0.1.1, rm 0.1) stay on this repository's
release page.
